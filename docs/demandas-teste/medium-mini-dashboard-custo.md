# Demanda MEDIUM — Mini Dashboard de Custo

## Configuração sugerida

- Complexidade: MEDIUM
- Resultado esperado: interface
- Setor: d11 — Design & Produto
- Prioridade: MEDIUM

## Título

Mini dashboard de custo por demanda

## Descrição

Crie uma tela HTML de dashboard simples para visualizar custo operacional de demandas. A tela deve conter:

- resumo com custo previsto, custo real e diferença;
- lista com três demandas fictícias;
- filtro visual por complexidade;
- indicador de risco quando custo real passar do previsto.

O foco é validar layout e interação, não conectar com dados reais.

## Critérios de aceite

- Entregar HTML com CSS e JavaScript embutidos.
- Filtro por complexidade deve alterar a lista visível.
- Mostrar pelo menos um caso dentro do orçamento e um acima do previsto.
- Manter o conteúdo curto para economizar tokens.
