# Demanda LOW — Card de Status Operacional

## Configuração sugerida

- Complexidade: LOW
- Resultado esperado: interface
- Setor: d11 — Design & Produto
- Prioridade: LOW

## Título

Card de status operacional simples

## Descrição

Crie uma tela HTML pequena com um card central de status da frota. A tela deve mostrar:

- título da operação;
- status atual;
- última execução;
- custo estimado;
- botão visual "Atualizar" sem integração real.

Use visual limpo, responsivo e com modo escuro simples.

## Critérios de aceite

- Entregar um HTML funcional.
- O botão deve ter interação visual.
- Não usar bibliotecas externas.
- Não criar múltiplas telas.
